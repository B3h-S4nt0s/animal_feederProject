# Animal Feeder Project

This is a multi-platform project for managing pet food based on established technologies.

**Technologies used:**

- **Prisma Orm**
- **(SQlite Database/ MongoDB)**
- **TypeScript**
- **JavaScript**
- **EJS**
- **Express**

## Project Description

The project aims to be implemented for the general public, providing a way to understand and manage a database, make complete connections, and generate a secure and reliable app.

An app that manages an IoT device through a web-mobile application, completely programmed from scratch, to its complete form, viewable on any digital medium.

By blocking login and registration, anyone outside the application's terms will not be able to access it.
